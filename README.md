A deterministic Python program that writes one haiku about debugging — exactly 5-7-5 syllables, 70 characters — to `/output/entry.txt`. The haiku was chosen from six hand-counted candidates by pairwise comparison: one line fixed at dawn, a dozen break by breakfast, and the bug had children.

## Run it

```sh
python3 main.py
```
